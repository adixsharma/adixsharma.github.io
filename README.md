# adixsharma.github.io

Personal portfolio site for Aditya Sharma, software engineer (embedded systems, backend, full-stack).

Live at **https://adixsharma.github.io**

## Stack

Static HTML and CSS with no build step, served by GitHub Pages.

- `index.html` — single-page site: experience, projects, skills, education, contact
- `style.css` — all styling
- `AdityaSharma_Resume_JULY26_Summary.pdf` — resume linked from the site

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
